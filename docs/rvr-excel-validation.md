# RvR Excel 工具 v1.0 驗證紀錄

驗證日期：2026-10-09。原模擬器維持 v0.3.1，新增獨立 RvR Excel 工具 v1.0。

## 程式與瀏覽器

- TypeScript 與正式建置通過。ESLint 通過。
- 115 個單元測試通過：原模擬器 99 個，量測資料解析與 Excel 匯出 16 個。
- 19 個 Playwright Chromium 測試通過：原模擬器 16 個，新工具 3 個。
- 新工具單一 HTML 在 `file://` 下可啟動、貼入獨立 ON／OFF 測點、下載 XLSX，無 HTTP／HTTPS 請求與瀏覽器程式錯誤。
- 驗證 CSV／TSV／空白／分號、數字小數、實測 0、空白量測、排序成對、重複 dB、非數字、錯誤欄數、1,000 點上限。
- 修改成錯誤數據會阻擋下載，沒有沿用舊曲線當成新結果。同 dB 比較不插值，OFF 為 0 不做百分比除法。
- 模式切換保留各自的來源欄位。示範只載入目前模式，來源不會自動套用到其他模式。
- 390 px 手機寬度無頁面水平溢出；已檢查桌面截圖、曲線斷點、圖例、輸入與下載控制。

## Excel 原生功能

Excel 範本以 Artifact Tool 建立，原生 XY 曲線的 X 軸參照與直線模式在匯出後補正。兩個工作表皆完成渲染檢查，交付範本的輸入區為空白，沒有示範點或虛構量測。

- Single 原生曲線參照 A7:A1006 與 B7:B1006。
- TxBF ON 參照 A／B，OFF 使用獨立 D／E 範圍，不強迫相同 dB 格點。
- 原生 `lineMarker` 散佈圖、數值 X／Y 軸、藍 ON／紅 OFF、空白顯示為 gap。
- 使用 Windows 已安裝 Excel 開啟範本，辨識 ChartType 74（原生 XY 直線帶標記），兩組 ON／OFF 的 SERIES 公式正確。
- 在測試副本修改 B7 至 123.5 Mbps、保留空白與 0，新增第 1,000 個測點 99 dB／1.25 Mbps，計算、刷新並另存成功。另存檔的原生圖表快取保留 123.5、實測 0、空白缺點及末點 1.25。
- 使用獨立 openpyxl 讀取器與 ZIP／XML 檢查交付範本及瀏覽器下載的單曲線／TxBF 檔，驗證原生圖表、來源文字、數值型別、空白與 active sheet。
- Excel 另行開啟工具下載的 TxBF 檔，讀到 7.5 dB／920.25 Mbps、中文來源與正確 SERIES 公式。此輪後續另存步驟被本機 Office「授權合約過期」限制阻擋，未將這一步記為通過。工具自行產生 XLSX 的下載及檔案結構檢查已通過。此測試沒有修改使用者的 Office 授權或正式交付範本。

範本每條曲線固定最多 1,000 點，第 1,007 行之後須另行延長圖表參照。廠商多欄 MSP 原始報表尚需選出指定的 dB／Mbps 欄位。網頁同 dB 的差值與增益目前僅提供預覽，未匯出為 Excel 公式。
