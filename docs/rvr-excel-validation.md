# RvR Excel 工具驗證紀錄

## v1.2（2026-10-12）

新增獨立圖表標題、曲線名稱、配色、實線／虛線／點線／僅測點、線寬、測點形狀與大小、圖例及格線開關。預覽與原生 Excel 使用相同設定。標題連結 A2、圖例連結 B6／E6；保留原生 XY、各組獨立 X 範圍、1000 點、空白與實測零值。沒有工作表或圖表保護。擷取加入按列模式、X／Y 行指定及包含終點的行／欄範圍；自動模式仍取左上首組連續數據。

- 165 項單元測試通過：原模擬器 99、RvR 既有 28、新矩陣解析 31、原生圖表外觀 7。TypeScript、正式打包、ESLint 通過。
- 23 項瀏覽器測試通過：原模擬器 16、新工具 7。新工具驗證離線無網路請求、標題／圖例、顏色／線型／測點、原生匯出、橫向矩陣與起訖範圍、各模式保留各自設定及 390px 無頁面溢出。
- 範本以 Artifact Tool 編輯說明、欄名與標題格式，補回原生 XY、標題／圖例儲存格引用與缺值 gap。沒有把曲線換成圖片或補造數值。渲染檢查空白範本與實際下載的兩個工作表；透過 Artifact Tool 核對標題、來源與量測點。
- 本機 Windows Excel 開啟實際瀏覽器下載的自訂檔，ChartType=74，標題公式 `=TxBF!$A$2`，ON 公式 `=SERIES(TxBF!$B$6,TxBF!$A$7:$A$1006,TxBF!$B$7:$B$1006,1)`。ReadOnly=False、ProtectContents=False、ProtectDrawingObjects=False、ProtectedViewWindows=0。
- 在獨立 Excel 副本中改 A2、B6、B7=123.5，標題、圖例與量測曲線實際更新。線條顏色／線寬／虛線、三角形測點／大小及 SERIES X／Y 範圍可修改。此機的現代 `Format.Line` COM 介面拒絕存取，改用原生 `Border` 介面完成格式驗證。
- **另存及重開未通過**：Excel 明確回報「因為使用此應用程式的授權合約過期，所以無法使用此命令」。未修改 Office 授權、安全性、正式輸出檔或使用者已開啟的工作階段。網站生成及下載 XLSX 正常，檔案原生編輯功能已驗證，Office 另存限制仍需處理。

## v1.1（2026-10-10）

新增 MSP 矩陣位置擷取、起始行與欄號修改、自訂 X／Y 欄名與原生 Excel 軸名。保留首組連續數據，明確顯示右側未選取欄位與下方未匯入行數。圖片 OCR 尚未加入。

127 個單元測試通過，含 28 個 RvR 資料／匯出測試；正式建置、TypeScript 和 ESLint 通過。原模擬器 16 個瀏覽器測試保留，新工具驗證離線下載、來源、矩陣擷取、欄名與數值軸、手動欄號、手機排版。

使用者回報的 Excel 檔凍結前 6 行，圖表從第 6 行開始；原生 XML 的 pane 為 `ySplit=6`、drawing 起點 row=5（從 0 計數），使圖表跨越凍結分界。以 Artifact Tool 編輯視窗設定，取消凍結並顯示格線。最終檔案僅替換兩個工作表的 sheetViews，其他所有 ZIP 內容、儲存格數值／樣式、原生圖表與快取均保持原樣。原始 Downloads 檔案未覆寫。

已渲染、檢查修正前後兩個工作表與空白範本，並以 Windows Excel 開啟修正版：FreezePanes=False、SplitRow=0、SplitColumn=0、DisplayGridlines=True。ScrollRow 依序為 1、13、50、1，圖表始終保持約 712.8 × 486 pt，ChartType=74；原始 ON 起點 980 Mbps 與 OFF 的空白測值保留。此輪僅驗證開啟與捲動，未依賴 Office 另存功能，也沒有測量 Excel 螢幕像素渲染。

## v1.0（2026-10-09）

驗證日期：2026-10-09。原模擬器維持 v0.3.1，新增獨立 RvR Excel 工具 v1.0。

## 程式與瀏覽器

- TypeScript 與正式建置通過。ESLint 通過。
- 115 個單元測試通過：原模擬器 99 個，量測資料解析與 Excel 匯出 16 個。
- 19 個 Playwright Chromium 測試通過：原模擬器 16 個，新工具 3 個。
- 新工具單一 HTML 在 `file://` 下可啟動、貼入獨立 ON／OFF 測點、下載 XLSX，無 HTTP／HTTPS 請求與瀏覽器程式錯誤。
- 驗證 CSV／TSV／空白／分號、數字小數、實測 0、空白量測、排序成對、重複 dB、非數字、錯誤欄數、1,000 點上限。
- 修改成錯誤數據會阻擋下載，沒有沿用舊曲線當成新結果。同 dB 比較不插值，OFF 為 0 不做百分比除法。
- 模式切換保留各自的來源欄位。示範只載入目前模式，來源不會自動套用到其他模式。
- 390 px 手機寬度無頁面水平溢出；已檢查桌面截圖、曲線斷點、圖例、輸入與下載控制。

## Excel 原生功能

Excel 範本以 Artifact Tool 建立，原生 XY 曲線的 X 軸參照與直線模式在匯出後補正。兩個工作表皆完成渲染檢查，交付範本的輸入區為空白，沒有示範點或虛構量測。

- Single 原生曲線參照 A7:A1006 與 B7:B1006。
- TxBF ON 參照 A／B，OFF 使用獨立 D／E 範圍，不強迫相同 dB 格點。
- 原生 `lineMarker` 散佈圖、數值 X／Y 軸、藍 ON／紅 OFF、空白顯示為 gap。
- 使用 Windows 已安裝 Excel 開啟範本，辨識 ChartType 74（原生 XY 直線帶標記），兩組 ON／OFF 的 SERIES 公式正確。
- 在測試副本修改 B7 至 123.5 Mbps、保留空白與 0，新增第 1,000 個測點 99 dB／1.25 Mbps，計算、刷新並另存成功。另存檔的原生圖表快取保留 123.5、實測 0、空白缺點及末點 1.25。
- 使用獨立 openpyxl 讀取器與 ZIP／XML 檢查交付範本及瀏覽器下載的單曲線／TxBF 檔，驗證原生圖表、來源文字、數值型別、空白與 active sheet。
- Excel 另行開啟工具下載的 TxBF 檔，讀到 7.5 dB／920.25 Mbps、中文來源與正確 SERIES 公式。此輪後續另存步驟被本機 Office「授權合約過期」限制阻擋，未將這一步記為通過。工具自行產生 XLSX 的下載及檔案結構檢查已通過。此測試沒有修改使用者的 Office 授權或正式交付範本。

範本每條曲線固定最多 1,000 點，第 1,007 行之後須另行延長圖表參照。廠商多欄 MSP 原始報表尚需選出指定的 dB／Mbps 欄位。網頁同 dB 的差值與增益目前僅提供預覽，未匯出為 Excel 公式。
