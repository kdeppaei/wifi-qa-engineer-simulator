# RvR Excel 繪圖工具使用方式

這個對話持續維護兩項工作：Wi-Fi QA 模擬器，以及 MSP 測試完成後使用的 RvR Excel 繪圖工具。新工具獨立處理貼入的數據，沒有連線或控制 AP／MSP，也不依賴模擬器狀態。

## v1.1：直接貼上 MSP 矩陣

選單曲線後，可直接貼上整塊數值矩陣。預設尋找最靠左上的第一組連續數據，將最左兩欄定義為 **dB** 與 **Throughput (Mbps)**。上方文字標題與左側空白欄可略過，右側其他欄位不放入曲線。共用 ON／OFF 模式則擷取 dB／ON／OFF 三欄。

工具會顯示起始行、實際欄號、未選取欄位和下方未匯入行數。按「核對已擷取欄位」可檢查每組前 20 行。空白行或統計／下一組標題會結束本區塊，不會自動把多輪測試合併。資料若排列不同，展開「修改擷取範圍」設定起始行與欄號；1 是貼入內容的最左欄，留白恢復自動。ON、OFF 可分別設定範圍。

可改寫「X 欄名稱」與「Y 欄名稱與單位」。新名稱會帶到預覽、下載檔的欄位與原生圖表座標軸。這是更改顯示名稱，不進行單位換算；輸入仍須為非負數字。

這版採用矩陣數值擷取，**尚未加入圖片 OCR**。若是圖片，需要先轉成文字表格再貼入。曲線截圖無法等同原始量測數據，後續圖片功能會優先支援數值表格並提供校對。

Excel v1.1 取消凍結窗格並恢復格線。舊版凍結前 6 行，圖表也從第 6 行開始，因此圖表跨過凍結分界而在捲動時被切開。既有下載檔可在 Excel 的「檢視／凍結窗格／取消凍結窗格」修正；新版下載檔與範本已套用修正。

## 直接在 Excel 畫圖

開啟 `rvr-excel-template.xlsx`。這是空白範本，沒有預先放入示範量測。

1. 單條曲線：選 **Single** 工作表，從 **A7** 貼上兩欄。A 是衰減 dB，B 是吞吐量 Mbps。
2. TxBF 比較：選 **TxBF**，從 **A7** 貼 ON 的 dB／Mbps，從 **D7** 貼 OFF 的 dB／Mbps。ON 用 A／B，OFF 用 D／E，各組可用不同 dB 測點。
3. 保持 dB 和 Mbps 成對。數字本身不要附上單位，單位已在標題中。圖表是原生 XY 散佈圖加直線，數值軸會依真實 dB 間距排列，改動儲存格後更新。
4. 每組最多 1,000 行，即第 7 至 1,006 行。超出這個範圍的測點不會進入圖表。
5. 換一輪測試前，選取原數據範圍按 Delete 清除內容，再貼新資料。保留第 6 行標題和圖表。空白是未量測、曲線斷開；數字 0 是實測 0 Mbps。
6. 可修改 A4 的來源文字，填入自己的測試名稱或條件。範本只檢查非負數字；重複 dB、排序與兩輪測試條件仍需自行確認，或先使用下方工具檢查。

建議以「另存新檔」保留每次測試。不要只排序 dB 欄，應一起排序該組 dB／Mbps 兩欄。

## 先預覽，再下載 Excel

直接用 Chrome／Edge 開啟 `rvr-excel-tool.html`。檔案內含程式與 Excel 範本，不需伺服器、網路或安裝套件。

1. 選「單條曲線 · 兩欄」、共用 dB 的「TxBF ON／OFF · 三欄」，或「TxBF ON／OFF · 各兩欄」。
2. 從 MSP 結果或 Excel 複製整塊矩陣貼入文字框。可接受 Tab、逗號、分號或空白分隔；Tab／CSV 能保留空白欄。預設只取左上方第一區塊的兩欄／三欄。
3. 可匯入 UTF-8 CSV／TSV／TXT，限 2 MB。各兩欄模式的檔案匯入目前填入 ON，OFF 請另行貼上。多欄原始報表依位置擷取，不依廠商欄位名稱猜測；可手動調整欄號與起始行。
4. 逐行檢查提示。選取資料中的重複 dB、非數字、負數、指定欄不存在或超過 1,000 點會阻擋匯出。空白 Mbps 保留，至少要有一個有效量測點。貼入新資料若有錯誤，舊曲線不會繼續當成目前結果。
5. 「按 dB 排序」會成對排序整組數據；取消即可保留原順序。ON 和 OFF 分別排序，沒有替測點補零或插值。
6. 選擇數據來源並填入測試條件，例如 `5 GHz / TCP DL / 4 streams`。來源由使用者標示，不會自動認定是實機量測。示範按鈕會明確標示「非實機量測」。
7. 檢查圖表。滑鼠停在測點可看到 dB／Mbps。ON／OFF 表只對齊相同且皆有量測的 dB；OFF 為 0 時不計算增益百分比。
8. 按「下載 Excel 原生圖表 .xlsx」。下載檔保留 Single 與 TxBF 兩個工作表，並開啟對應模式；另一張留空供下次使用。下載後可繼續在 Excel 修改原生儲存格和圖表。

例如單曲線輸入：

```text
dB	Mbps
0	980
7.5	950.25
20	850
90	0
```

TxBF 共用 dB：

```text
dB	ON Mbps	OFF Mbps
0	980	950
10	920	870
20	850	740
90	0	0
```

工具不保存瀏覽器存檔。關閉或重新整理前請先下載，避免遺失尚未匯出的貼入資料。下載的是量測數據與原生圖表；網頁中的同 dB 差值／增益表目前作為預覽，未放進 Excel。

## 推薦下一步

優先加入數值表格截圖 OCR 與識別結果校對，並用實際 MSP CSV 支援更多報表區塊和測試條件辨識。其次加入同條件多次重測的平均與變異，以及 Excel 內同 dB 的差值／增益公式。目前不假設 TxBF ON 一定較快，曲線完全使用輸入的數值。
