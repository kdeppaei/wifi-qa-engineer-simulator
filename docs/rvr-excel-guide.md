# Excel 繪圖與表格工具使用方式

## v1.4：公開網址與報告表格

直接開啟 [Excel 工具](https://excel-chart-table-tools.kdeppaei2.chatgpt.site)，任何持有網址的人都可使用，不需要 Node.js 或指令。另一項工作有獨立的 [Wi-Fi QA 實驗室網址](https://wifi-qa-virtual-lab.kdeppaei2.chatgpt.site)，兩個頁面可互相切換。

先選「曲線繪圖」或「Peak 結果表」。曲線再選兩欄、共用三欄或各兩欄格式，依「輸入 → 調整 → 匯出」操作；進階選取及外觀可按需展開，圖表預覽保持可見。下載按鈕在預覽工具列，資料有錯誤或尚未輸入時會顯示原因。

Excel 採報告表格版面，保留原始值和原生編輯：Peak 的預設篩選箭頭及背景格線隱藏，淡色交錯列及配置分隔線便於比較；標題、條件、單位與列印設定隨匯出保存。若要篩選，可在 Excel 的「表格設計」重新勾選「篩選按鈕」。曲線工作表移除黃色輸入底色與主報告的操作教學，仍可點選圖表編輯資料參照、標題及格式。

網站輸入只在本機瀏覽器處理，不會上傳量測資料。Excel 工具重新整理會清空輸入，請先下載。

這個對話持續維護兩項工作：Wi-Fi QA 模擬器，以及 Excel 繪圖與表格工具。第二項工具獨立處理輸入的數據，支援曲線及 Peak 結果表，沒有連線或控制 AP／MSP，也不依賴模擬器狀態。名稱已擴充，既有檔名 `rvr-excel-tool.html` 與網址保留，v1.4 不需要更換入口。

## v1.3：Peak 結果表

按「Peak 結果表 · 七欄」開始，預設為 Band/Config、Channel、Direction、Gain Criteria、SU、MU、Gain。

1. 每個設定組填一個 Band/Config 和 Channel。預設 `6G_UHR320 / 37`，可自由改成 `5G_UHR160`、`2G_UHR40` 或自己的配置名稱。Channel 只檢查正整數，不會替你推定頻道適用性。
2. 勾選 UL／DL／BI；預設 UL 和 DL，所以產生兩列。每個方向各自填 Gain Criteria、SU、MU、Gain。多個頻道可新增多個設定組，保留相同 Band/Config、使用不同 Channel。
3. **Gain 只手填，沒有自動計算或 Pass／Fail 判定**。純數值會存成 Excel 數字；例如 `12%`、`待確認` 則保留原文字。SU／MU 空白保留空白，0 是數值 0。單位預設 Mbps，可自行改寫；改單位不換算量測值。
4. 修改配置／頻道、暫時取消方向、隱藏欄位或切換曲線頁籤，已填資料仍保留。重新勾選方向會恢復該方向的值。移除含資料的設定組會先在頁面要求確認，可復原最近一次移除。
5. 展開「客製化欄位與表格外觀」，可改欄名、移動順序、顯示／隱藏、欄寬、標頭顏色、字級、小數位數、交錯列底色；也可新增文字或數字手填欄。預設欄位可隱藏，新增欄位可移除。顯示中的欄名必須不同，方便 Excel 原生篩選表格使用。
6. 直接在編輯表填值，展開格式預覽核對顯示效果。小數位數只控制格式，匯出仍保留原始數值精度。最多 1,000 個方向列、20 欄。
7. 「下載 Peak Excel .xlsx」保留所有顯示中的資料與外觀；「下載 Peak 空白表 .xlsx」保留配置、頻道、方向、欄名及外觀，清空量測欄與新增手填欄。不會清除畫面上的已填值。

Excel 只有一張 `Peak Results` 工作表，標題在 A2、第 6 行為欄名，第 7 行開始為資料。是真正的 Excel Table，有篩選功能；可修改儲存格、欄名、格式或新增表格列。沒有圖表、圖片、公式或工作表保護。`peak-results-template.xlsx` 是空白範本，含預設 UL／DL 結構，沒有預填量測。

例子：`6G_UHR320 / 37` 勾 UL、DL，會展開：

| Band/Config | Channel | Direction | Gain Criteria | SU   | MU   | Gain |
| ----------- | ------- | --------- | ------------- | ---- | ---- | ---- |
| 6G_UHR320   | 37      | UL        | 手填          | 手填 | 手填 | 手填 |
| 6G_UHR320   | 37      | DL        | 手填          | 手填 | 手填 | 手填 |

## v1.3：調整曲線時保持預覽可見

曲線設定與圖表並排，設定面板可單獨捲動，圖表保持可見。視窗較小或要仔細調色時，按「放大並固定預覽」，左側捲動調整、右側即時看圖；小螢幕改成上方圖表、下方設定。按「結束放大編輯」或 Esc 返回，設定與數據不會清除。鍵盤 Tab 保持在放大編輯區內。

## v1.2：圖表標題、外觀與行／欄選取

在右側「圖表標題」輸入大標題，會同步到預覽、Excel 的 A2 與圖表標題。「測試名稱／條件」仍作來源說明，與大標題各自保存。Excel 直接改 A2 即可更新圖表；直接在圖表上改寫標題會解除 A2 連結，可在 Excel 標題公式列重新輸入 `=TxBF!$A$2`（單曲線為 `=Single!$A$2`）。

展開「曲線顏色、線型與測點」，每條曲線可改名稱、顏色、實線／虛線／點線／不連線、線寬、圓形／方形／菱形／三角形／隱藏測點及大小。預覽與原生 Excel 套用同一組設定。提供藍橙搭配不同線型、黑白列印兩種快捷樣式，圖例與圖表格線可分別開關。曲線不能同時隱藏線條和測點。三種資料模式各自保留自己的標題與樣式。

左側「資料排列方式」可選：

- **按欄讀取**：每一行是一個測點，指定 X 欄、Y 欄；共用 ON／OFF 可各指定一個 Y 欄。可設起始行與結束行。
- **按列讀取**：每一欄是一個測點，指定 X 行、Y 行；共用 ON／OFF 可各指定一個 Y 行。可設起始欄與結束欄。

位置從 1 開始，包含貼上的標題與空白欄；結束位置包含在範圍內。留空使用自動擷取。明確指定範圍內遇到非數值或缺少欄位會報錯，不會偷偷忽略。各兩欄模式的 ON／OFF 可各自選擇排列方式。

例如橫向資料：

```text
Name	Point 1	Point 2	Point 3
dB	0	10	90
Mbps	980	900	0
```

選按列讀取，X 行 = 2、Y 行 = 3、起始欄 = 2、結束欄 = 4。核對選取摘要與前 20 行預覽後再下載。

## 直接貼上 MSP 矩陣

選單曲線後，可直接貼上整塊數值矩陣。預設尋找最靠左上的第一組連續數據，將最左兩欄定義為 **dB** 與 **Throughput (Mbps)**。上方文字標題與左側空白欄可略過，右側其他欄位不放入曲線。共用 ON／OFF 模式則擷取 dB／ON／OFF 三欄。

工具會顯示實際行／欄與擷取範圍。按「核對已擷取欄位」可檢查每組前 20 行。自動模式遇到空白或統計／下一組標題會結束本區塊，不會自動把多輪測試合併。ON、OFF 可分別設定範圍。

可改寫「X 欄名稱」與「Y 欄名稱與單位」。新名稱會帶到預覽、下載檔的欄位與原生圖表座標軸。這是更改顯示名稱，不進行單位換算；輸入仍須為非負數字。

這版採用矩陣數值擷取，**尚未加入圖片 OCR**。若是圖片，需要先轉成文字表格再貼入。曲線截圖無法等同原始量測數據，後續圖片功能會優先支援數值表格並提供校對。

Excel v1.1 取消凍結窗格並恢復格線。舊版凍結前 6 行，圖表也從第 6 行開始，因此圖表跨過凍結分界而在捲動時被切開。既有下載檔可在 Excel 的「檢視／凍結窗格／取消凍結窗格」修正；新版下載檔與範本已套用修正。

## 直接在 Excel 畫圖

開啟 `rvr-excel-template.xlsx`。這是空白範本，沒有預先放入示範量測。

1. 單條曲線：選 **Single** 工作表，從 **A7** 貼上兩欄。A 是衰減 dB，B 是吞吐量 Mbps。
2. TxBF 比較：選 **TxBF**，從 **A7** 貼 ON 的 dB／Mbps，從 **D7** 貼 OFF 的 dB／Mbps。ON 用 A／B，OFF 用 D／E，各組可用不同 dB 測點。
3. 保持 dB 和 Mbps 成對。數字本身不要附上單位，單位已在標題中。圖表是原生 XY 散佈圖加直線，數值軸會依真實 dB 間距排列，改動儲存格後更新。
4. 每組最多 1,000 行，即第 7 至 1,006 行。超出這個範圍的測點不會進入圖表。
5. 換一輪測試前，選取原數據範圍按 Delete 清除內容，再貼新資料。保留第 6 行標題和圖表。空白是未量測、曲線斷開；數字 0 是實測 0 Mbps。
6. 可修改 A4 的來源文字，填入自己的測試名稱或條件。範本只檢查非負數字；重複 dB、排序與兩輪測試條件仍需自行確認，或先使用下方工具檢查。

標題與曲線皆可編輯：A2 控制圖表大標題，B6／E6 控制圖例名稱。右鍵圖表選「選取資料」可修改 X／Y 來源；點選曲線後可在公式列查看 `=SERIES(名稱,X 範圍,Y 範圍,順序)`。右鍵曲線選「設定數列格式」可改線條、顏色與測點，軸也可右鍵調整上下限。檔案沒有工作表、圖表或物件保護。

若 Excel 顯示「受保護的檢視」，確認來源是自己的匯出檔後按「啟用編輯」。本機先前曾出現 Office 授權合約過期；這會限制編輯或另存，需由 Office 帳號／授權處理，網站無法解除。沒有自動停用安全性或修改 Office 授權。

建議以「另存新檔」保留每次測試。不要只排序 dB 欄，應一起排序該組 dB／Mbps 兩欄。

## 先預覽，再下載 Excel

直接用 Chrome／Edge 開啟 `rvr-excel-tool.html`。檔案內含程式與 Excel 範本，不需伺服器、網路或安裝套件。

1. 選「單條曲線 · 兩欄」、共用 dB 的「TxBF ON／OFF · 三欄」，或「TxBF ON／OFF · 各兩欄」。
2. 從 MSP 結果或 Excel 複製整塊矩陣貼入文字框。可接受 Tab、逗號、分號或空白分隔；Tab／CSV 能保留空白欄。預設只取左上方第一區塊的兩欄／三欄。
3. 可匯入 UTF-8 CSV／TSV／TXT，限 2 MB。各兩欄模式的檔案匯入目前填入 ON，OFF 請另行貼上。多欄原始報表依位置擷取，不依廠商欄位名稱猜測；可手動調整欄號與起始行。
4. 逐行檢查提示。選取資料中的重複 dB、非數字、負數、指定欄不存在或超過 1,000 點會阻擋匯出。空白 Mbps 保留，至少要有一個有效量測點。貼入新資料若有錯誤，舊曲線不會繼續當成目前結果。
5. 「按 X 排序」會成對排序整組數據；取消即可保留原順序。ON 和 OFF 分別排序，沒有替測點補零或插值。
6. 選擇數據來源並填入測試條件，例如 `5 GHz / TCP DL / 4 streams`。來源由使用者標示，不會自動認定是實機量測。示範按鈕會明確標示「非實機量測」。
7. 檢查圖表。滑鼠停在測點可看到 dB／Mbps。ON／OFF 表只對齊相同且皆有量測的 dB；OFF 為 0 時不計算增益百分比。
8. 按「下載 Excel 原生圖表 .xlsx」。下載檔保留 Single 與 TxBF 兩個工作表，並開啟對應模式；另一張留空供下次使用。下載後可繼續在 Excel 修改原生儲存格和圖表。

例如單曲線輸入：

```text
dB	Mbps
0	980
7.5	950.25
20	850
90	0
```

TxBF 共用 dB：

```text
dB	ON Mbps	OFF Mbps
0	980	950
10	920	870
20	850	740
90	0	0
```

工具不保存瀏覽器存檔。關閉或重新整理前請先下載，避免遺失尚未匯出的貼入資料。下載的是量測數據與原生圖表；網頁中的同 dB 差值／增益表目前作為預覽，未放進 Excel。

## 推薦下一步

- 保存／匯入圖表設定，讓同一款產品重測時沿用標題、選取範圍與公司配色。
- 匯出 SVG／PNG，方便貼入測試報告；Excel 繼續保留原生可編輯圖表。
- 數值表格截圖 OCR 與識別結果校對，配合實際 MSP CSV 支援報表區塊和測試條件辨識。
- Peak 支援一次貼上多列結果與 CSV 匯入，沿用手填 Gain，不加入計算。

目前不假設 TxBF ON 一定較快，曲線完全使用輸入的數值。
